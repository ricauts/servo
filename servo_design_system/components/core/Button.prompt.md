# Button

Primary action control; `variant` carries intent and `size` matches control height tokens.

```jsx
<Button variant="primary" iconStart={<Icon name="sparkles" size={14} />}>Run AI resolver</Button>
```
Variants: primary (green fill, dark ink), outline, ghost, subtle (green wash), danger (red wash — Reject), link. Sizes xs/sm/md/lg/xl; md (32px) is the app default, xl for marketing CTAs. Press nudges down 1px.
