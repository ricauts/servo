# ApprovalCard

The human-approval gate: what the agent wants to run, verbatim, with a risk meter, how long it has been blocked, an optional diff preview, and Approve/Reject.

```jsx
<ApprovalCard ticketNumber={1061} ticketTitle="Star on GitHub button is unreadable" toolName="github_merge_pr" toolInput={json} risk="HIGH" requestedAt="4m ago" canDecide={false} />
```
