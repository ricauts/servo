# Marketing site UI kit

The servoai.org landing page, rebranded onto the dark Servo identity. Copy is
lifted from the repository README (features, quickstart) and from the landing
page visible inside the product screenshots in `docs/assets/` — nothing is
invented about what the product does.

- `index.html` — page shell, loads the bundle + Lucide
- `Landing.jsx` — nav, hero + live ticket panel, how-it-works, features, self-host block, footer

Only the landing page exists in the sources, so only the landing page is here.
